## 其他未覆盖边界

- 自定义操作系统贡献、Windows／PowerShell 软件配方和运行时新增软件依赖目前被拒绝，不在“接口已有类型”的意义上视作完成。
- 对话会话的服务器目录工具／远程 shell 仍是历史待实现设计；不能照旧方案直接更新组 ID，绕过现在的软件／类型预检。
- 未提供人工强制解除未知远端操作的完整流程；远端变更可能部分成功，必须保留事实。
- 列表完整 SQL 下推优化未实施，且用户此前要求暂不做；当前数据持久化不受此限制影响。

## 接手时保留的约束

当前数据可能已有测试服务器、密钥、观察和历史。早期允许破坏兼容不等于如今数据库为空；容器插件切换按计划检查实际记录、进行中操作和键转换。保留旧执行历史身份，旧未开始计划重新预检，不保留长期旧键别名。

只修改文档或 UI 时不顺手安装／升级真实服务器软件，不清空无关数据。临时验证插件只由测试装载，正式 CES 只显式加载需要的正式插件。分支操作、提交和推送按具体任务指令执行。
