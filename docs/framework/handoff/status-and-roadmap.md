## 静态核对到的限制

| 限制 | 交接含义 |
| --- | --- |
| `accounts/wallets` 没有仓库建表迁移 | 不能承诺 clone 后空库安装完整可用；需既有基线或单独补建库方案 |
| migration runner 无全局迁移锁／历史摘要 | 文件名记账不等于多进程迁移或旧文件改动自动安全 |
| 服务器列表／升级建议有应用层筛选与分页 | 接口分页不等于 SQL 下推；规模优化尚未做 |
| 升级计划固定取最近 200 条且无分页 | 更早计划不会通过该列表翻页取得；检测结果也只有最近 200 条策略检查，见[接口地图](../modules/server-management/http-api.md) |
| 周期巡检目前选择 online 服务器 | 不是所有离线主机自动重连的完整心跳机制 |
| 巡检历史未区分手动／周期来源 | 非准备类 inspect 仅 failed／blocked 单条展示；手动成功也按小时汇总，排队／运行记录需按 ID 查 |
| 当前 Linux 观察仍尝试容器读取 | 与“是否安装必要软件”开关不是同一条件，后续插件化才改变 |
| 当前统一状态不聚合容器扫描失败原因 | 任务失败和列表正常可能分别反映不同事实 |
| 工作区组无逐贡献撤回句柄 | 不能照服务器定义租约机制承诺其热卸载语义 |
| 模型同步未显式 await 在途同步清理 | 需针对卸载边界进一步验证，不能直接套用已验证的任务执行清理保证 |
| 数据页换 Fernet key 不重加密旧数据 | 保存 key 不是完整轮换流程 |

这些是文档核对结果，本次未修复，也不自动插入已确认八步计划。后续如安排处理，应有独立问题、变更和验证记录。

本轮文档更正及逐项源码证据见[文档复核记录](document-review.md)。

当前 CES 开发分支是 `ces/develop`。基线和平台分支不自动包含这里所有业务改造，切换前核对提交和构建产物；用户未明确要求时不删除分支。
