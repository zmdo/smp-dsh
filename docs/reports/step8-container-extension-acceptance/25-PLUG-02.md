# 25 PLUG-02：临时插件卸载与重载

- 用例：PLUG-02
- 结果：通过
- 测试时间：2026-10-21 01:55 CST
- 插件：`@smp/test-group-plugin`

## 卸载

从本地 profile 移除依赖、bundle 和符号链接后重启。

证据：

```json
[{"group_key":"database-group","available":false}]
```

服务器：

```text
name: vacant-with-docker
type_key: @smp/test-group-plugin/database
type_available: false
status: attention
group_name: 数据库组
```

结论：

- 服务器登记身份保留。
- 类型不可用并显示需关注。
- 分组名称和历史仍可读。
- 没有删除服务器。

## 重载

恢复 profile 和符号链接后重启。

证据：

```json
[{"group_key":"database-group","available":true}]
```

服务器：

```text
type_available: true
status: normal
group_name: 数据库组
```

结论：

- 插件重载后分组和类型恢复。
- 没有重复创建分组。
- 服务器自动恢复正常。
