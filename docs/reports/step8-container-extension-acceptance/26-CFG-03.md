- 结果：通过

## 步骤

1. 读取当前配置：revision 0。
2. 用 revision 0 保存 `{collect:false}`。
3. 模拟另一个页面仍持有 revision 0，再保存 `{collect:true}`。
4. 用新 revision 1 恢复 `{collect:true}`。

  ```json
  {"value":{"collect":false},"revision":"1"}
  ```


  ```json

  ```
