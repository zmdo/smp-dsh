# 50 GROUP-06：删除用户分组

- 用例：GROUP-06
- 结果：前两项通过；系统组删除未验证
- 测试时间：2026-10-21 04:40 CST
- 用户组：`delete-test-2`

## 非空组

1. 通过 move 计划把 `ui-test` 移入用户组。
2. 确认服务器 `group_name` 变为 `delete-test-2`。
3. 删除用户组。

结果：

```json
HTTP 409
{
  "code": "type_change_requires_preflight",
  "detail": "这次类型变更需要软件预检；当前分组和类型未改变"
}
```

非空组没有被删除，但错误码和文案不直观：实际原因是组内仍有服务器，提示却说“类型变更需要预检”。

## 空组

1. 通过 move 计划把服务器移出用户组。
2. 删除用户组。

结果：

```json
HTTP 204
```

组被删除。

## 结论

- 非空用户组删除被拒绝：通过
- 移出服务器后可以删除：通过
- 系统组不可删除：未验证
- 非空组拒绝的错误提示需要改进
