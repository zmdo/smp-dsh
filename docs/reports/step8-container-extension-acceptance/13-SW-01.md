# 13 SW-01：安装缺失软件

- 用例：SW-01
- 结果：部分通过
- 测试时间：2026-10-20 21:15 CST
- 对象：`container-missing`（43.128.72.83）

## 前置状态

- 无 Docker、无 Compose。
- 服务器状态 `attention`，软件状态 `missing`。

## 步骤

1. 调用 `POST /console-api/servers/:id/install-components`。
2. 等待任务。
3. 检查机器 Docker／Compose。
4. 检查软件状态和容器巡检。

## 结果

- 任务 `install_components` 返回 `succeeded`，结果为 `prepared`。
- 机器最终安装：
  - Docker 29.1.3
  - Compose 2.40.3
- 软件状态变为 `installed`。
- 安装后首次巡检仍失败：
  ```text
  permission denied while trying to connect to the docker API
  ```
  原因：ubuntu 用户未加入 `docker` 组。
- 手工执行：
  ```sh
  sudo usermod -aG docker ubuntu
  ```
  新 SSH 会话后巡检成功，容器清单为空。

## 发现

- 安装软件包本身成功。
- 安装流程没有把 SSH 用户加入 `docker` 组，导致安装后仍无权限。
- `install_components` 返回 `prepared`，实际安装由变更计划完成；需要确认产品是否应自动确认安装计划，当前行为不够直观。

## 结论

软件安装成功，但安装后的 Docker 权限没有自动就绪，需要补产品处理或明确前置要求。
