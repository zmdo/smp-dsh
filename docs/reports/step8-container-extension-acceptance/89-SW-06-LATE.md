# 89 SW-06：迟到结果不覆盖当前状态

- 用例：SW-06 迟到结果
- 结果：通过
- 测试时间：2026-10-21 10:20 CST
- 依据：报告 57

## 场景

安装任务执行中取消，远端安装继续完成。

## 结果

- 任务保持：
  ```json
  {
    "state": "cancelled",
    "result": null,
    "output_excerpt": "任务已取消。"
  }
  ```
- 计划保持 `cancelled`
- 机器最终安装了 Docker
- 迟到结果没有覆盖任务状态或写入 result

## 结论

取消后的迟到结果被隔离，不能覆盖当前状态。
