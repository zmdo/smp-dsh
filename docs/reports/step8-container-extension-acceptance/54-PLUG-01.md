# 54 PLUG-01：两个插件同时存在

- 用例：PLUG-01
- 结果：部分通过
- 测试时间：2026-10-21 04:55 CST

## 环境

同时加载：

- `@smp/console-server-containers`
- `@smp/console-server-extension-fixture`

公共类型：

```json
[
  "builtin/vacant",
  "@smp/console-server-containers/container",
  "@smp/console-server-extension-fixture/database"
]
```

## 隔离

容器服务器扩展目录：

```json
[
  "inspection:@smp/console-server-containers/container-check",
  "query:@smp/console-server-containers/container-list",
  "settings:@smp/console-server-containers/container-settings",
  "panel:@smp/console-server-containers/containers"
]
```

数据库测试服务器扩展目录：

```json
[
  "inspection:@smp/console-server-extension-fixture/database-check",
  "settings:@smp/console-server-extension-fixture/database-execution",
  "panel:@smp/console-server-extension-fixture/database-panel",
  "settings:@smp/console-server-extension-fixture/database-settings",
  "query:@smp/console-server-extension-fixture/database-status"
]
```

没有互相串入。

## 未覆盖

- 一个插件组件报错时另一个不受影响
- 中英文切换不改变贡献身份

## 结论

两个插件可以同时加载，类型、面板和配置按服务器类型隔离。
