# 41 CFG-04：保存期间插件卸载／类型变化

- 用例：CFG-04
- 结果：通过
- 测试时间：2026-10-21 03:58 CST

## 场景一：计划生成后卸载插件

1. 生成执行配置计划。
2. 从 profile 移除测试插件并重启。
3. 应用旧计划。

结果：

```json
{
  "code": "extension_not_found",
  "detail": "扩展不存在。"
}
```

计划没有写入。

恢复插件后读取配置，仍是：

```json
{"value":{"mode":"mutate"},"revision":"1"}
```

没有变成旧计划的 `observe`。

## 场景二：计划生成后更改服务器类型

1. 生成执行配置计划。
2. 将服务器从测试数据库类型迁移到容器类型。
3. 应用旧配置计划。

结果：

```json
{
  "code": "extension_unavailable",
  "detail": "扩展不适用于当前服务器。"
}
```

计划没有写入。

## 结论

插件卸载或服务器类型变化后，旧扩展配置计划不能生效；不会把旧插件/旧类型的配置写到新状态。
