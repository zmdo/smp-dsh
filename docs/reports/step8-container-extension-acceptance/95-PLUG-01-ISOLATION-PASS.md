# 95 PLUG-01：一个插件组件报错不影响另一个

- 用例：PLUG-01 组件错误隔离
- 结果：通过
- 测试时间：2026-10-21 11:25 CST

## 步骤

1. 打开数据库插件服务器 `db-test`，确认数据库面板正常。
2. 返回服务器列表，打开容器服务器 `manual-test`。
3. 设置容器面板崩溃开关，首次打开容器面板。
4. 返回服务器列表，再打开 `db-test` 数据库面板。

## 结果

数据库面板（崩溃前）：

```text
数据库管理
数据库扩展示例面板已加载。
```

容器面板（崩溃）：

```text
The extension component failed to load.
```

数据库面板（崩溃后）：

```text
数据库管理
数据库扩展示例面板已加载。
```

## 结论

一个插件组件崩溃：

- 只影响容器面板
- 数据库插件面板继续可用
- 没有导致整页崩溃

已勾选“一个插件组件报错不影响另一个”。
