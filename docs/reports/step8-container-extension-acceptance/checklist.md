## 1. 验收目标

本清单用于验证：

1. 核心在不加载容器插件时只保留空置类型，基础详情、任务、终端、配置可用。
2. 容器插件独立提供容器类型、软件、配方、面板、设置、巡检和查询。
3. 空置类型即使机器已有 Docker，也不出现容器入口或容器巡检。
4. 容器检测、安装、升级、批量升级、权限失败和 daemon 异常都有确定结果。
5. 临时测试插件能通过公开契约注册新类型和系统组，分组登记、移动和改类型正常。
6. 两个插件并存、卸载、重载、配置并发和任务取消不串数据、不泄漏。
7. 终端、任务报告、配置滚动和窄屏 UI 不回归。

## 2. 测试环境

- 控制台：`http://127.0.0.1:9090`
