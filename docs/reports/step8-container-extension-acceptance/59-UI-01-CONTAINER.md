# 59 UI-01：容器面板高度和滚动

- 用例：UI-01 容器面板
- 结果：部分通过
- 测试时间：2026-10-21 05:50 CST
- 对象：`ui-container`（16 个容器）

## 结果

- 表格行数：16
- 表格自身：
  ```json
  {"clientHeight": 722, "scrollHeight": 722}
  ```
- 扩展层：
  ```json
  {"clientHeight": 166, "scrollHeight": 882, "overflowY": "auto"}
  ```
- 页面：
  ```json
  {"clientHeight": 900, "scrollHeight": 900}
  ```

## 观察

- 页面没有外层滚动
- 滚动发生在扩展层
- 容器表格本身不滚动
- 扩展层可视高度只有 166px，16 行容器时需要滚动整个面板

## 结论

页面滚动隔离通过，但容器面板高度偏小，内容由整个扩展层滚动，不是表格滚动。是否可接受需要产品确认。
