# 45 SW-06：租约过期与恢复

- 用例：SW-06
- 结果：部分覆盖，未形成有效恢复证据
- 测试时间：2026-10-21 04:15 CST
- 计划：`e4c9f9ab-3277-4df1-9da3-bcfff0f7ff15`

## 步骤

1. 对 `lease-test`（43.128.72.83）创建 Docker 安装计划。
2. 确认执行。
3. 任务进入 running 后，直接把 `server_jobs.lease_expires_at` 改为过去时间。
4. 等待 40 秒。

## 结果

最终：

```json
{
  "job": "succeeded",
  "target": "succeeded",
  "plan": "completed",
  "recovery_attempts": 0
}
```

机器安装了 Docker 29.9.1 和 Compose 5.6.0。

## 分析

虽然手工把租约改成过期，但任务仍然由原 worker 完成，`recovery_attempts` 仍为 0。

可能原因：

- worker 心跳在过期后重新续租
- 原 worker 持有远端监督进程锁并继续执行
- 没有真正让 worker 停止

因此这次不能证明：

- 租约丢失后另一个 worker 能恢复
- 远端 journal 能防止重复安装

## 结论

SW-06 仍未被有效验证。

要真实验证，需要：

1. 任务执行中停止控制台进程，模拟 worker 死亡。
2. 等租约过期。
3. 重启控制台。
4. 验证新 worker 读取远端 journal 并完成或安全失败。
