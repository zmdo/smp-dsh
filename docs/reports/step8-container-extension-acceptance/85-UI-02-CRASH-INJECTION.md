# 85 UI-02：容器面板注入渲染错误

- 用例：UI-02 扩展组件异常
- 结果：部分通过
- 测试时间：2026-10-21 10:05 CST

## 方法

临时在容器面板组件顶部注入：

```ts
if (globalThis.__SMP_CRASH_CONTAINER_PANEL__) throw new Error('container panel crash test')
```

打开容器面板时组件主动抛错。

## 结果

- 浏览器没有整页崩溃
- 扩展区域显示：
  ```text
  The extension component is not loaded.
  ```
- 页面其他区域仍在

## 问题

- 错误提示和“组件缺失”使用同一文案，无法区分渲染异常
- 关闭注入并切回详情再进容器面板，面板仍为空；需要刷新页面才恢复

## 结论

组件异常被隔离在扩展区域，没有导致整页崩溃；但错误边界没有独立错误提示，且异常后同一会话内不能自动恢复。
