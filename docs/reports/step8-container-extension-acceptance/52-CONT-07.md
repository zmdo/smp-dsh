# 52 CONT-07：Docker daemon 停止

- 用例：CONT-07
- 结果：通过
- 测试时间：2026-10-21 04:50 CST
- 对象：`daemon-test`（43.128.69.189）

## 准备

- 清空控制台服务器和任务
- 启动测试容器 `daemon-test`
- 巡检成功，容器清单包含该容器

## 停止

只停止 `docker.service` 时，socket 激活仍会拉起 daemon，测试不成立。

改为同时停止：

```sh
sudo systemctl stop docker.socket
sudo systemctl stop docker
```

## 结果

巡检失败：

```text
Cannot connect to the Docker daemon at unix:///var/run/docker.sock
```

服务器状态：

```text
unverified
```

Docker 软件状态：

```json
{"state":"unknown","last_known_version":"29.9.1","detail":"Cannot connect to the Docker daemon..."}
```

容器查询仍保留上次成功清单：

```json
[{"name":"daemon-test","status":"Exited ..."}]
```

## 恢复

启动 `docker.socket` 和 `docker.service` 后重新巡检：

```text
succeeded
```

## 结论

- daemon/socket 不可用时错误明确
- 上次成功容器清单保留
- 恢复 daemon 后巡检成功
