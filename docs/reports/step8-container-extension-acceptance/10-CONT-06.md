# 10 CONT-06：Docker 权限不足

- 用例：CONT-06
- 结果：失败
- 分支：`ces/detail-extensions`
- 测试时间：2026-10-20 21:00 CST
- 环境：`http://127.0.0.1:9090`，本地测试 PostgreSQL，真实 SSH 测试服务器

## 对象

- `container-restricted`（43.153.204.197，用户 `smp-limited`）

## 前置条件

- 机器已安装 Docker 29.1.3。
- `smp-limited` 无 sudo，无 docker 组。
- 验证：
  ```text
  NO_SUDO
  permission denied while trying to connect to the docker API at unix:///var/run/docker.sock
  ```

## 步骤

1. 执行巡检。
2. 读取任务和服务器状态。
3. 准备打开容器面板。

## 证据

- 任务状态：`failed`
- 服务器状态：
  ```json
  {"code":"unverified","reasons":[
    {"code":"software_unknown","parameters":{"software":"@smp/console-server-containers/docker-engine"}}
  ]}
  ```
- Docker 软件状态：
  ```json
  {"state":"unknown","detail":"permission denied while trying to connect to the docker API at unix:///var/run/docker.sock"}
  ```

## 未通过原因

- 任务失败但服务器状态仍是 `unverified`，不是“需关注”。
- 容器面板查询只返回空行，不包含权限错误；用户可能误以为“没有容器”。
- 需要让扩展查询返回错误，或让面板读取服务器软件诊断并展示。

## 结论

SSH 连接本身成功，权限错误有记录；但用户界面状态和面板诊断不满足验收要求。
