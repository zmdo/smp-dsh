# 44 TERM-03：切换服务器终止旧终端

- 用例：TERM-03
- 结果：关键行为通过，旧 socket 关闭未直接观测
- 测试时间：2026-10-21 04:05 CST

## 改进后的测试方法

第一次测试没有等待终端出现 shell 提示符，导致输入未进入 xterm。

这次改为：

1. 等终端出现 `ubuntu@...:~$`
2. 再执行终端操作
3. 返回服务器列表
4. 打开另一台服务器
5. 再打开终端
6. 等新终端出现提示符

## 证据

切换前终端：

```text
ubuntu@VM-0-11-ubuntu:~$
```

切换后终端：

```text
Last login: ... from 115.171...
ubuntu@VM-0-9-ubuntu:~$
```

页面状态：

- `.xterm` 数量：1
- 新终端没有旧服务器输出
- 新终端提示符主机名不同：`VM-0-9` 对 `VM-0-11`

## 结论

切换服务器后：

- 页面只保留一个终端实例
- 新终端连接的是新服务器
- 没有把旧服务器输出带到新终端

旧 WebSocket 是否立刻关闭没有直接抓包确认，但主机名和单实例已经证明新会话替换旧会话。
